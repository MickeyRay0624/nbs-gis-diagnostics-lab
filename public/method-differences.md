Version 0.8 · 22 September 2026. This table distinguishes implemented methods from inputs still needed for an independent comparison. An agreed pilot district is not confirmation of a particular boundary file or scientific definition. Software tests establish computational consistency; they do not establish agreement with the original assessment.

## Files required for the original-assessment comparison

Use [reference-comparison-files.csv](reference-comparison-files.csv) as the intake manifest. Do not replace missing reference files with a visually similar screenshot.

1. Original report and appendices, expected module figures/tables and their stated units; comparison AOI and period.
2. Authoritative AOI with CRS, geometry validity, holes/exclusions, administrative vintage and full Shapefile sidecars if applicable.
3. Original classified rasters for every year, QA/NoData masks, source/version/date/scale metadata and SHA-256 digests.
4. Crosswalk CSV, forest-definition note, edge width/connectivity rules, protected-area and OECM polygons with dates, overlaps and completeness notes.
5. Exported GEE `.js`, ArcPy `.py` and environment/package versions; every imported GEE asset ID plus accessible frozen exports. A shared editor URL alone is insufficient.
6. Native groundwater/NDVI/LST/climate inputs or provider IDs, baselines, seasons, completeness/quality filters, scenarios, model members, thresholds and unit conversions.
7. Expected reference rasters, full transition matrices, forest metrics by period/stratum, numeric area-weighted summaries and source coverage tables.
8. A comparison plan agreed on before inspecting differences: common CRS/extent/NoData footprint, pixel agreement, class-area totals, matrix margins, metric-specific absolute/relative tolerances and treatment of stochastic model differences. No arbitrary blanket tolerance is claimed here.

## Comparison sequence

Freeze and hash the files → check AOI and grid → compare source classifications → compare common-coverage areas and matrix margins → compare whole-AOI forest classes → check strata and metric denominators → compare numeric periods/thresholds → record explained and unexplained differences. Retain both original and platform output packages. The current automated regression suite is a separate source of evidence.
