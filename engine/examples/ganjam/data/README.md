# Required input rasters

Place the approved categorical LULC rasters here using these filenames:

- `lulc_2002.tif`
- `lulc_2012.tif`
- `lulc_2022.tif`

The files are intentionally absent. Obtain either the frozen India reference rasters or an approved retrieval route from the GIS team before treating any output as a project result.

The rasters must contain one integer-valued categorical band and a declared CRS. They do not need to share a grid; the engine aligns them with nearest-neighbour resampling.
