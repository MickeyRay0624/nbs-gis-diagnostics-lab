# Ganjam pilot configuration

This directory is the intake package for the proposed India golden case.

The real Ganjam district boundary is already connected. The three LULC rasters and the detailed-to-project class crosswalk remain deliberately empty so preflight reports a blocked state instead of generating unsupported results.

Before the first reference run, the GIS team must confirm:

- the authoritative AOI boundary;
- raster source, version and exact years;
- the detailed-class to ten-class crosswalk;
- NoData and resampling rules;
- priority-grid size, significant-change thresholds and tie-breaking rules;
- the maps and tables that constitute the frozen expected output.
